# AL — state education directory sources

Agency: Alabama State Department of Education (ALSDE)

Download date: 2026-10-21

ALSDE's online Education Directory (eddir.alsde.edu) now redirects to the AIM login portal (aim.alsde.edu) — not usable without an account. The newest public directory is the annual PDF **Directory of Alabama Public Schools 2025** (cover dated November 2024, released with State Superintendent memo FY25-1001 on 2025-01-07); no 2025-26 edition was found (WordPress media search on alabamaachieves.org for "DAPS"/"Directory of Alabama" returned 2025 as latest). It is a PDF (no spreadsheet). For each city/county system and charter: board members, superintendent name + phone, program key contacts, and every school with principal name, grades, school code, address, phone, fax, website. Emails: essentially none (30 '@' occurrences in the whole document, mostly state staff).
