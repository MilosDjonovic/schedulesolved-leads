Federal NCES files (CCD/PSS/IPEDS) are not duplicated here.

## States with nothing usable

- **NC** (blocked): EDDIE (https://apps.schools.nc.gov/eddie, linked from https://www.dpi.nc.gov/nceddirectory/) is behind a Cloudflare bot challenge (HTTP 403 to curl; challenge never clears in headless Chromium); old hosts eddie.ncpublicschools.gov / eddie.dpi.nc.gov no longer resolve via proxy (502). No other NC DPI school/principal file found.
- **AZ** (blocked): www.azed.gov (school directory page, https://www.azed.gov/school-directory) and www.ade.az.gov/edd (Educational Directory) sit behind a Cloudflare challenge (403 'Just a moment...' in curl and headless Chromium). The public AZ School Report Cards API (https://azreportcards.azed.gov/api/Entity/GetEntityList) lists 3,109 entities but no contacts, and its contact endpoint /api/Entity/GetContactDetails returns 'An error occurred while processing the request.' for every entity tried. Nothing saved.
- **MD** (none): MSDE publishes no principal/superintendent directory file. The Maryland Report Card (https://reportcard.msde.maryland.gov) school lists carry only school names/codes; its Data Downloads 'NCES School Directory' zip (FileDownload/580) is a repackaging of the federal NCES directory (already held) and returned HTTP 500 to direct requests. MSDE's own Directory page lists only state agency staff.
- **ID** (login required): Idaho SDE's 'Idaho School, Superintendent, and Principal Mailing Lists' (https://apps.sde.idaho.gov/IDCI/Contact/MailingList, linked from https://www.sde.idaho.gov/contact-us/) redirects to an ADFS sign-in (adfsproxy2010.sde.idaho.gov). The old Educational Directory page (sde.idaho.gov/ed-directory.html) is 404. Public SDE files (List-of-Charter-Schools.pdf, Alternative-Secondary-School-List.xlsx) have no contact names/emails. Nothing saved.
- **ND** (none): NDDPI's former school district directory page (nd.gov/dpi/districtsschools/school-district-directory) is 404; nd.gov/dpi sitemap has no directory page; DPI only collects LEA/School Directory data (MIS01/MIS02) via its STARS reporting system and publishes no statewide principal/superintendent file. Only program-specific lists exist (e.g. Special Education Directory PDF). Nothing saved.

## Notes and caveats

- **MS:** the Mississippi Department of Education states on its District Directory page that the listed email addresses "should not be used for solicitations by vendors or bulk email campaigns." Review before using MS emails for sales outreach.
- States with **no contacts** in the saved file (addresses/IDs only): CT, DE (and the school files of CO, WV, DC public/independent).
- Several sites block plain HTTP clients (Akamai, Imperva/Incapsula, Cloudflare, Radware, CloudFront). Where the public page loaded in a normal headless Chromium browser, files were fetched that way (NJ, NY, NH, RI, TN, VT, WI, etc.); no logins were used and no challenges were bypassed. Where a challenge never cleared (NC, AZ), the state is listed above.
- HTML-page states (VA division staff, HI, RI, MS) are saved as raw rendered/served HTML (zipped where many pages); CO superintendents are a raw Smartsheet data payload.
- Counts in the table are data rows from the saved files; some files include closed/inactive entities (see each SOURCE.md).
