# OR — state education directory sources

Agency: Oregon Department of Education (ODE) — Oregon School Directory 2026-27

Download date: 2026-10-21

ODE publishes the directory only as a combined PDF (no spreadsheet), updated every few months; the latest (updated September 22, 2026) was saved. Per district: superintendent and key district staff (name, phone), district email (generic, e.g. tcrider@nbend.k12.or.us style — about 255 email addresses in the whole document, mostly district-level), website, Institution IDs; per school: principal name, phone, fax, grades, Institution ID. Includes a private schools section (names/addresses; ODE notes private schools need not register).
