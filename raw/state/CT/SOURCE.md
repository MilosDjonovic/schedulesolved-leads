# CT — state education directory sources

Agency: Connecticut State Department of Education (CSDE) — Education Directory on the CT Open Data portal (data.ct.gov)

Download date: 2026-10-21

**No contacts.** CSDE states the former Connecticut Education Directory (which had superintendent/principal names) has been replaced by EdSight ("Find School/District"), which offers no bulk contact export. The open-data Education Directory (dataset 9k2y-kqxn, maintained by CSDE, updated 2026-10-01) lists public, charter, magnet, regional, technical and state-agency schools and districts (no private schools) with address, phone, grades and organization codes only. No CSDE private-school contact file found.
