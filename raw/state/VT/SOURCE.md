# VT — state education directory sources

Agency: Vermont Agency of Education (AOE) — Public Schools / Independent Schools directories

Download date: 2026-10-21

education.vermont.gov is behind AWS CloudFront rules that return 403 to plain curl; the two Excel files were downloaded in headless Chromium and the PDF with curl using a browser User-Agent. Lists dated 07-2026. **No email addresses** in the AOE principal/superintendent lists (names, phone, fax, address). Independent (private) schools: PDF directory (revised September 21, 2026) with a contact name and phone per school.
