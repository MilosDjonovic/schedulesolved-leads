# IL — state education directory sources

Agency: Illinois State Board of Education (ISBE) — Directory of Educational Entities

Download date: 2026-10-21

One workbook, 8 sheets (Category Guide + 7 data sheets). `Administrator` holds the superintendent name on `Dist` rows and the principal name on `Sch` rows. **No email columns** anywhere in the ISBE directory. NCES IDs are on public sheets. Nonpublic schools are on sheet `5 Non Pub Sch` (with administrator name). The landing page labels this file "Directory of Educational Entities - Current (Updated nightly)"; dated yearly snapshots (e.g. 2025-26-Directory-Ed-Entities.xlsx) are also on the page.
