# NM — state education directory sources

Agency: New Mexico Public Education Department (NMPED) — New Mexico Public Schools Directory

Download date: 2026-10-21

Data snapshot dated 09-2024 (files posted 2025-01-14); a WordPress media search on web.ped.nm.gov for 'nmpsd' found no newer version. Principal and superintendent files carry `FirstName`, `LastName`, `ElectronicMailAddress`. The legacy SharePoint "Superintendents/Principals Directory" (webed.ped.state.nm.us) reset the connection and was not used. No NMPED private-school contact file found.
